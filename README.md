# homebrew-tap

Homebrew tap for projects of <https://github.com/dex4er>.

Usage:

```sh
brew tap dex4er/tap
brew install --cask tf
```

`tf` ships prebuilt binaries, so it is distributed as a cask rather than a
formula. It installs on both macOS and Linux.

If you installed `tf` from this tap before it became a cask, `brew upgrade`
migrates you over automatically.
